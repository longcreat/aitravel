- **环境变量配置**：必须配置 `JWT_SECRET`、`OPENAI_API_KEY`/`OPENAI_BASE_URL` (或 DashScope 相关变量)、`SMTP_*` (用于验证码邮件)。
- **数据库迁移**：启动时自动执行 `app/db/bootstrap.py` 中的 SQL Migration，支持通过 `DEV_RESET_CHAT_DB=true` 重置开发环境数据库。
- **MCP 配置**：需在 `config/mcp.servers.json` 中定义 MCP 服务器连接参数。
- **运行命令**：通常通过 `uv run uvicorn app.main:create_app --factory` 启动服务。
