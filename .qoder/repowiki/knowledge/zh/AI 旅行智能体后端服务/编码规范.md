- 所有服务类（如 `AuthService`, `ConnectorService`）均接收 `sqlite_db_path` 作为构造参数，实现存储层与业务逻辑的解耦。
- API 路由模块（如 `app/api/chat.py`）通过 FastAPI 的 `Depends` 注入全局单例服务，保持路由层轻薄。
- 异步流式响应统一采用 `StreamingResponse` 配合 `text/event-stream` 媒体类型，并在异常时产出标准化的 `error` SSE 事件。
- 数据库操作统一在 `with self._connection() as conn:` 上下文管理器中执行，确保事务的自动提交或回滚。
- 敏感配置（如 OAuth Client Secret）在存入 SQLite 前必须通过 `app/connectors/crypto.py` 进行加密，读取时解密。
