- **入口与生命周期**：`app/main.py` 作为 FastAPI 应用入口，通过 `lifespan` 管理 `TravelAgentService` 的启动（初始化 Agent 运行时）与关闭（释放 MCP 连接）。
- **核心业务门面**：`app/agent/service.py` (`TravelAgentService`) 是核心协调层，封装了聊天流式调用 (`stream_invoke`)、会话管理、版本控制及语音生成逻辑。
- **Agent 运行时**：`app/agent/runtime.py` 负责装配 LangGraph Agent，集成全局工具、MCP 工具集及用户级动态工具；通过 `app/agent/middleware.py` 实现动态提示词注入（时间、元信息）和运行时模型档位切换。
- **数据持久化**：采用 SQLite 作为主要存储，`app/db/bootstrap.py` 管理 SQL Migration；`app/memory/sqlite_store.py` 实现复杂的会话、消息版本及语音资产映射逻辑；LangGraph Checkpoint 也基于 SQLite。
- **外部集成**：`app/connectors/` 模块处理 OAuth 2.0/PKCE 流程，管理第三方 MCP 服务器的授权与 Token 刷新；`app/mcp/` 模块负责加载和初始化 MCP 客户端。
- **依赖注入**：`app/api/deps.py` 使用 `lru_cache` 提供全局单例的服务实例（Agent, Auth, Connector），确保进程内状态共享。
