- **Web 框架**：FastAPI + Uvicorn。
- **AI 编排**：LangChain (v1) + LangGraph (v1) + LangGraph Checkpoint SQLite。
- **模型适配**：支持 OpenAI 兼容接口及阿里云 DashScope (Qwen/QwQ) 专用适配器 (`langchain-qwq`)。
- **协议集成**：Model Context Protocol (MCP) via `langchain-mcp-adapters`。
- **认证与安全**：PyJWT (HS256) 用于会话令牌，`cryptography` 用于加密存储 OAuth 密钥。
- **包管理**：使用 `uv` (pyproject.toml + uv.lock) 进行依赖锁定与管理。
