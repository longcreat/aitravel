- **技术栈**: 采用 Vite + React 19 + TypeScript 架构，使用 React Router v7 进行路由管理，Tailwind CSS 配合 Radix UI Primitives 实现样式与组件。
- **目录结构**: 遵循特性驱动开发 (Feature-Sliced) 模式：`features/` 封装业务模块（auth, chat, profile），`shared/` 提供跨模块复用资源（UI 组件、工具函数、布局），`app/` 负责应用组装与路由配置，`pages/` 作为路由入口层。
- **状态与数据流**: 使用 React Context (`AuthProvider`) 管理全局认证状态；聊天核心逻辑封装在 `useChatAgent` Hook 中，通过 SSE (Server-Sent Events) 实现流式响应处理；API 调用集中在各 feature 的 `api/` 目录下，通过统一的 `http` 客户端发起请求。
- **关键文件**: `src/main.tsx` 为应用入口，`src/app/routes/index.tsx` 定义路由表，`vite.config.ts` 配置别名 `@` 指向 `src` 目录并集成 Vitest 测试环境。
