- 采用 Tailwind CSS 原子类进行样式编写，并通过 `cn()` 工具函数（结合 `clsx` 和 `tailwind-merge`）处理动态类名合并。
- UI 组件库基于 Radix UI 无头组件构建，统一存放在 `shared/ui/primitives` 目录下，并通过 `shared/ui/index.ts` 集中导出。
- 业务逻辑与 UI 分离，每个 Feature 内部严格划分为 `api`（接口定义）、`model`（状态/类型）、`ui`（组件）和 `hooks`（逻辑复用）子目录。
- HTTP 请求统一通过 `shared/lib/http.ts` 中的 `http` 对象发起，自动注入 Bearer Token 并处理通用错误逻辑。
